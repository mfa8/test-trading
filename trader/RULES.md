Save verbatim as `trader/RULES.md` on first wake. All market times are US/Eastern (ET = UTC−4 through 2026-11-01; convert every market-data timestamp per W-7a). ## 3. THE PER-WAKE ALGORITHM

W-0 Day rollover. On the first wake whose ET date (broker clock; on fast-path wakes the skew-corrected system clock) differs from state.today.date: today = {date:<new>, entries:0, attempts:{}, losses:0, pnl_pct:0, day_halt:false, cooldown_until_et:null, stopped_symbols:[], done_checkpoints:[], armed:{}, vwap_acc:{}, or:{}, open_px:{}, day_hi:{}, day_lo:{}, halt:{}, eod_done:false, analyst_status:"NONE"}; seq_today=0; last_bar_evaluated={}; campaign.ext_rejects_tonight=0; mode ∈ {COOLDOWN, DAY_HALT} → FLAT; if yesterday was a session: sessions_done += 1, expire resting_legs dated before today; sod_equity := account.last_equity at the next account fetch. If the new date is the first session on/after a Monday: entries_week=0, week_start=<date>, week_sod_equity=E at the first fetch. done_checkpoints and last_bar_evaluated are always written dated ("YYYY-MM-DD HH:MM").
W-1 Pseudo-code:
```
W-0 rollover check
read state.json; HUMAN_STOP exists → mode=CLOSING(HUMAN) (Z-8); note HUMAN_GO for B-4
if mode in {HALTED, DONE}: hourly → positions + open orders must both be []; else → KILLING/CLOSING + ALERT; heartbeat; return
if mode == HALTED_BOOT: every 30 min re-run B-3/B-4 (resume BOOT if clear or HUMAN_GO); else heartbeat; return
if mode in {KILLING, CLOSING}: run Z-9 step machine only (INV-1 still evaluated); write; return
if system_now < backoff_until_utc:
    flat and no open orders → journal BACKOFF; return
    else MANAGE-ONLY wake: get_clock, snapshot(held symbol), get_orders(open) (+account every 5th minute for INV-1), ≤4 calls,
         then W-5b/W-5f/W-5a; exit orders allowed; skip everything else; a 429 here doubles backoff but never suppresses the next manage-only wake

if light_wake_ok(): get_clock (+15-min account/positions/orders → INV-1, reconcile); return   # W-3
```

## 5. SETUPS (exactly three; long-only; every price is the traded ETF's own)

**Gates G** (all true, on data fetched this wake): is_open; inside the setup's window per today's FINAL plan; mode ∈ {FLAT, ARMED} (cooldown expired); not DAY_HALT/SAFE_MODE; today.entries < zone cap, entries_week < 7, entries_total < 14; symbol not stopped today, not resting/banned, not within 30 min of a halt; not inside a plan no_entry_window; §7 budget OK; X-3 pricing gate; INV-11/Z-5 asserts; W-7a self-test passed. These setups are variance-entry triggers that truncate the left tail on trend days — assume ≈ 0 edge per trade; the P&L comes from 2–3 trend days and capped carries.

## 6. SIZING, COMPOUNDING & RISK

Z-1 Sizing (every entry; show arithmetic): E = min(E_broker, E_bid) this wake; P = rounded limit; d from the setup; N = min(f × E, r × E/d, tier cap × E, 0.98 × BP_avail), BP_avail = min(buying_power, non_marginable_buying_power) − open-order reservations (CASH modes: settled_cash − $1); S3 uses N_ovn (C-2) in place of f × E. Z-2 f and r: f(zone) from Z-3; f = min(zone f, 0.70) if any of {DOWNSHIFT, the last two sessions were both losing days, stops_mode SYNTHETIC_ONLY, data_mode DELAYED_15}. r caps risk_usd = N·d ≤ r·E and rarely binds; the real risk lever is f with d: r_eff ≈ 3.5–6% (SOX, PRESS ≤ 7.1%) / 1–2% (NDX) per trade at f = 1.0.

CLOSING outside RTH, or no session open (CLOSED phase), or EXT_HOURS_OK=false: place nothing; sell at the first wake with is_open=true and clock ≥ 09:30:05. Z-10 Path math: at full notional one SOXL R ≈ 3.5–6% of E, so $200 needs Σ ln(1 + R_i × r_eff) ≈ 0.69. With ≤ 14 entries at a 35–40% hit rate, ≈ 8 non-winners at −1 to −1.25R cost ≈ −0.30 log, so winners must supply ≈ +1.0 log: e.g., five captures of ≈ +22% of E (≈ +5R, SOXL running ≈ +20% past entry) or four +19% captures plus three +2.5% carries. E_adj ≥ 172 → a typical +16% NVDL reaction crosses $201 by itself.

(2) First wake ≥ 15:44 with the account confirmed flat (positions re-fetched): buy the vehicle — marketable limit per X-3/X-1a, TIF day, coid …-E, INV-11 journal line with d = 0.5 × atr_vehicle, ≤ 2 attempts, none submitted after 15:52:00; unfilled by 15:54 → cancel, no shot, §10 hard-block stands (you are already flat). (3) On fill: native day stop at P × (1 − 0.5 × atr_vehicle) for the RTH remainder (expires 16:00 — intended; the event is the risk you chose); position.setup = "Z12", class SS2X (NVDL) or SOX, overnight_ok = true, event_shot_used = true; at 15:50 SKIP C-1 for this position; journal "Z-12 WAIVER: INV-10, C-1(f), U-1 overnight, N-10, §10 hard-block waived for <coid>"; ALERT (info) "event shot live: <sym> $N, worst case ≈ $X". ## 7. ROUND-TRIP BUDGET ENGINE

RT-1 Each Analyst wake re-read the B-4 fields (and HUMAN_NOTE) and confirm account_mode per B-5. A surprise (PDT field appears non-null, cash wording, PDT/GFV/unsettled/free-riding reject text) → switch to the stricter mode at once and permanently, ALERT, never retry the rejected order, never argue with the broker.
RT-2 LEGACY_PDT: day trade = a buy then any sell of the same symbol in one session (several sells after one buy on one date count once). Ledger daytrades_5d (dated) pruned to the last 5 sessions by broker calendar; used = max(broker daytrade_count, ledger count); every same-day sell you perform (probe, stop fill, partial, trim, flatten, kill) is appended in the same wake. Permissions: used ≤ 1 → S3 daily plus at most ONE S1/S2 entry per session, A+ days only; used = 2 → S3 only (a failed 15:50 carry flatten becomes #3 — legal); used = 3 → no new positions until one ages out. Never open a position you could not legally stop out today; never use the broker's reject as the guard; prior-session positions are always freely exitable. PDT-text reject of ANY sell (stop placement, exit, trim, kill): never resend that payload; (i) if it was an exit attempt, try once to place/keep the native day stop (accepted → that is the protection until 16:00); (ii) set position.pdt_locked_until = next trade date; no further sell orders on the symbol until the first session belonging to that trade date — 20:00 ET overnight session if overnight_tradable ∧ EXT_HOURS_OK, else 04:00 pre-market (X-1c pricing), else 09:30:05 market — then exit, unless C-1 evaluated at 15:50 said HOLD (then manage normally from 09:31); (iii) meanwhile only INV-1 is watched and even a KILL sell waits for that window (journal KILL_DEFERRED_PDT; mode stays KILLING); (iv) broker daytrade_count becomes the floor of `used` for the next 5 sessions; (v) DAY_HALT today, ALERT CRITICAL, tomorrow's entries require used ≤ 1; (vi) PDT rejects never count toward X-7.
RT-3 CASH_T1: ledger settled_cash and unsettled[{amt, settles_on = next session}] from fills; each morning reconcile with the broker's settled field (lower wins). Buy only if N ≤ settled_cash − $1, so every lot is settled-funded, a same-day stop is never a GFV, and free-riding is impossible. Consequences: after a same-day exit those dollars are locked until the next session; keep S3 carries ≤ 50% of E so the other half is settled for tomorrow's S3 (two alternating tranches); an A+-day S1/S2 may use all settled cash and then you are flat until tomorrow. There is no "I'll hold it overnight anyway" exception.
RT-4 CASH_SETTLED_ONLY: the broker enforces RT-3; its buying-power field is truth; same tranche rule.
RT-5 In every non-IM_FREE mode the primary engine is S3 (enter 15:30, exit next session = zero day trades, always settled) plus carries; S1/S2 only on A+ mornings within RT-2/RT-3. Expect ≤ 6 trades in the campaign and P($200) < 0.5%; say so in STATUS.md and BOOT_REPORT.
RT-6 IM_FREE (expected at Alpaca "limited margin", multiplier 1): no regulatory round-trip cap, proceeds instantly reusable; binding constraints are buy ≤ buying_power, one resting sell per symbol (INV-9), fractional TIF=day, wash-trade rejects, and this manual's self-caps (2/day, 7/week, 14/campaign).

## 8. EXECUTION HYGIENE

X-1 Order types: entries = limit buy at the X-3 price, TIF day, extended_hours=false, 09:40–15:36 only. RTH exits = X-8 then close_position(symbol) or market sell of broker qty (stop-hit, kill, carry-flatten, time stop, invalidation — speed beats pennies on a 3× fund). Extended-hours exits exist only for Z-9(KILLING), C-5a, the PRE/POST/OVERNIGHT disaster rule, X-9 after 16:00:30, and Z-8 WON: limit sell, TIF day, extended_hours=true, priced per X-1c. Never send a market or non-extended order while is_open=false — it queues for the open. No entries outside RTH, ever.
X-1a Formatting before every submit: prices ≥ $1.00 → $0.01 (buy limits round UP; sell limits and sell-stop prices round DOWN); prices < $1.00 → $0.0001; qty → truncate to capabilities.qty_precision (Alpaca 9 dp; default 4); notional → 2 dp. Journal and assert on the rounded values.
X-1b Clock latency: any order must be submitted within 45 s of the get_clock that authorised it; otherwise re-fetch the clock and re-check the window. No MARKET order when the fresh clock reads ≥ 15:59:00 or is_open=false; between 15:59:00 and 16:00:30 send nothing; at the first wake ≥ 16:00:30 list open orders and cancel every non-extended-hours order (a queued market/day order is a defect, not a stop) before any extended-hours action.
X-1c Extended-hours exit price = bid × 0.995 (KILLING: × 0.99) only if a two-sided quote ≤ 90 s old with spread ≤ 1.5% exists; else last × 0.98 (KILLING × 0.97) from the freshest print (iex, else overnight feed, else delayed_sip); no print < 20 min old → place nothing this wake (the 09:30 market sell is the backstop). Re-price a resting ext-hours order only when its reference moved > 0.3%, at most once per 5 min (cancel → confirm → re-place, new coid). Two ext-hours rejects in one night → send nothing more until 09:30 and ALERT. EXT_HOURS_OK=false → B-10 rule (place nothing; market at first is_open wake).
X-2 Never use trailing_stop, bracket/OCO/OTO, gtc/opg/cls on fractional qty. One resting order per symbol: the protective day stop (off-hours: at most the single Z-8/X-1c limit). No resting take-profits.

REALTIME_IEX (expected) or quote_source=LAST_TRADE → the quote is a sanity check only: require latest-trade age ≤ 15 s and minuteBar.c within 0.3% of last; IEX quote absent/one-sided is acceptable, but a two-sided IEX quote > 1.0% wide → skip; P_ref = min(ask if present, last × 1.001); bid-tests (S1-3/S2-3) use max(IEX bid, last − $0.01). Cost control is A-9 realized slippage, not the IEX spread.
X-4 client_order_id = `T2X-{yyyymmdd}-{seq2}-{SYM}-{E|X|S|P}`; seq_today increments per intent. Before submit: append intent {coid, utc, sym, side, qty|notional, type, limit, stop, setup, reason, replaces?} to orders.jsonl; get_order_by_client_id(coid) + open orders + positions — exists or equivalent position → do not submit. After submit append {coid, broker_id, status}; next wake append final status/fill. No response / timeout / transport error = UNKNOWN: set PENDING_ENTRY (or PENDING_EXIT) with pending.coid, journal UNKNOWN, do not resend this wake. Next wake: get_order_by_client_id → found: adopt its status; not found: check positions and open orders; still nothing ≥ 120 s after submit → mark never_sent. Entries marked never_sent are NOT resent (the setup may fire again only at a later checkpoint through the gates); exits marked never_sent are resent with a new coid only after confirming no open sell exists on the symbol (INV-9).
X-5 Rejects (text is data): explicit 4xx → never resend the same payload; ≤ 1 adjusted retry under a new coid (notional→qty, re-rounded qty/price, re-priced limit), never after UNKNOWN. "insufficient qty"/"wash trade" → you broke INV-9: re-fetch position/open orders, cancel the resting or opposite order first. "insufficient buying power" → one re-size at 0.95 × fresh BP. PDT/GFV/unsettled → RT-1 and, for sells, RT-2(i–vi). "sub-penny"/"invalid price" → X-1a. Disclosure text → B-9(h). "market closed"/"halt" → W-5e / X-1b.
X-6 Partial fills: manage from broker qty; on the first wake showing filled_qty > 0 with the entry still open, cancel the remainder immediately and re-poll; place the native stop only once the buy reads canceled/filled; resize stops after partial exits (INV-4 ii).

Two consecutive rejects of a correctly-formed stop on an unencumbered position (stop_reject_streak) → stops_mode SYNTHETIC_ONLY for the campaign (Z-2, ALERT). Rejects mentioning wash trade, insufficient qty, PDT, sub-penny, or market-closed/halt do NOT count.

A sell reject "insufficient qty" → re-fetch position: 0 = done, else back to (1). EXIT_PRIMITIVE=close_all permits close_all_positions(cancel_orders=true) as one call for kill/flatten; with REPLACE_OK an urgent alternative is replacing stop_price up to bid × 0.998. Never end a wake unprotected unless mode=PENDING_EXIT with either the sell submitted or the stop cancel still awaiting confirmation (then the sell is the first action next wake, before W-5a).
X-9 15:50 → close choreography: decide at the first wake ≥ 15:50 (C-1). Flatten/trim via X-8 this wake (sell next wake if the cancel is unconfirmed); verify by 15:56; 15:56:00–15:58:59 still holding unintended qty → market sell on a fresh clock; 15:59:00–16:00:30 → nothing. ≥ 16:00:30: X-1b sweep, then if unintended qty remains: EXT_HOURS_OK → ext-hours limit sell per X-1c until 19:55, continue 20:00–04:00 if overnight_tradable, else resume 04:00; on a hard_block night for the symbol never stop trying (within X-1c's two-reject rule); EXT_HOURS_OK=false → market sell at 09:30:05. ## APPENDIX A — FORMULAS (own bars only; show arithmetic; persist inputs in plan/state)
- A-0 Units: atr ≡ ATR14%/100 (0.12 for ATR14% = 12.0). Every multiple "k·atr" in §4–§6 (0.15/0.20/0.25/0.30/0.50/0.60/1.20) is a fraction of price; gap, range, daymove, close-location, d, q, f, r are fractions; "%" is display only. Example: chase guard ORH × (1 + 0.25·atr) = 149.20 × 1.03.
- A-1 Daily (21 SIP daily bars ending yesterday): PC = last close; SMA5/SMA20 = mean of last 5/20 closes; TR_i = max(high_i, close_{i−1}) − min(low_i, close_{i−1}); ATR14% = 100 × mean over the last 14 bars of TR_i/close_i; trend filter ⇔ PC > SMA20.
- A-2 open = 09:30 1-min bar open (IEX; SIP-corrected at 09:51 if > 0.3% off); gap = open/PC − 1.
- A-3 ORH/ORL = max high / min low of 1-min bars in the OR window (default 09:30–09:34); OR mid = (ORH + ORL)/2; range = (ORH − ORL)/open; V5 = Σ volume; RVOL5 = V5 ÷ mean V5 of the prior 5 sessions (same feed). day_hi/day_lo = max/min of today's 1-min bar CLOSES plus the current minuteBar.c (not highs/lows — one bad tick must not poison them).
- A-4 VWAP from 09:30: vwap_acc.sum_pv += vw_i × v_i (vw missing → (h+l+c)/3), sum_v += v_i, last_bar_t; VWAP = sum_pv/sum_v; sum_v = 0 → VWAP unavailable → no S1/S2 trigger that checkpoint.
- A-5 U_B = max(open, PC) × (1 + 0.5·atr·√(m/390)), m = minutes 09:30→B; inverse legs use their own open/PC.
- A-6 R_usd = (fill − initial_stop) × qty; P/L in R = (px − fill) × qty / R_usd; daymove = last/PC − 1; close-location = (last − day_lo)/(day_hi − day_lo) (undefined range → 0); E_at_stop = E − (px − stop) × qty.
- A-7 g = (200/E_adj)^(1/D) − 1; glide path = start_equity × 1.065^sessions_done; floors: kill 50, stop-out floor 53 (Z-5/W-5f), overnight floor 55 (C-2), PRESERVE < 57; overnight test N_ovn ≤ (E − 55)/stress, stress 0.30 SOX / 0.15 NDX; q (C-5b) = max(0.020, 0.50·atr) NDX / max(0.035, 0.30·atr) SOX.
- A-8 Daily-reset drag ≈ (L² − L)/2 × σ_daily²: SOXL at σ_SOX 4% ≈ 0.48%/day — fine for 1–4 trend nights, poison in chop; ride, never invest.
- A-9 slip_bps = 10⁴ × (fill − reference)/reference, reference = last at submit; plan with 15 bps/side; trailing-6-fill average > 35 bps → Analyst switches S1 OFF for that pair and notes it.
- A-10 Definitions: loss/win/scratch/losing day/entry/week per Z-6; monitoring wake = ET minute ∈ {00,15,30,45}; TIER-1/TIER-2 per S3-1; "fresh" = fetched this wake and ≤ 90 s old (entries: trade ≤ 15 s); WHOLE_SHARE partials: qty ≥ 2 → one 1/2 partial at +3R in LOCK, qty = 1 → none; probe_dust = the deferred $1 SPY probe lot; sessions_done = completed sessions since BOOT day inclusive.
